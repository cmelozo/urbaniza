# Urbaniza 
O **Urbaniza** é um sistema de denúncias urbanas que permite aos cidadãos registrar problemas encontrados na cidade, como buracos, lixo, iluminação pública e outros.

## Objetivo
Facilitar a comunicação entre a população e os responsáveis pela solução dos problemas urbanos.

## Funcionalidades
- Cadastro de denúncias
- Descrição do problema
- Localização da ocorrência
- Adição de imagens
- Acompanhamento das denúncias
